# 🍔 QuickBite Restaurant Analytics Dashboard

## Project Overview

This project analyzes restaurant operations using SQL Server and Power BI.

The dashboard provides insights into:

- Sales Performance
- Product Analysis
- Store Performance
- Customer Analysis

---

## Tools Used

- SQL Server
- Microsoft SQL Server Management Studio
- Power BI Desktop
- DAX

---

## Dataset

The dataset contains:

- Customers
- Orders
- OrderItems
- Products
- Employees
- Stores

---

## Dashboards

### Executive Dashboard

- Total Revenue
- Total Orders
- Total Customers
- Monthly Revenue Trend

### Product Analysis

- Top Products
- Revenue by Category
- Products Sold
- Product Revenue Distribution

### Store Performance

- Revenue by Store
- Orders by Store
- Monthly Revenue
- Revenue Share

### Customer Analysis

- Customer Distribution
- Loyalty Members
- Revenue by Customer
- Registration Trend
